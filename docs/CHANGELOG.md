# CHANGELOG

## 0.1.0 — 2026-11-05

- 初版。アフロCMS のインタラクティブデモ（主要 9 画面＋設定）
- 実装済み機能・未実装機能は `README.md` を参照

## 0.2.0 — 2026-11-05

- レスポンシブ対応を強化（360〜1440px とスマホ横向き）
  - タッチ環境ではボタン・タブ等の押せる大きさを 44px 以上に、文字は 12px 以上に
  - スマホではダイアログを全画面表示に（ページ作成・画像選択・ページ追加・比較・診断など）
  - 下部タブ・固定バーに内容が隠れないよう余白を調整（iPhone のセーフエリア対応）
  - サイトマップのキャンバスが画面全体を占めてスクロールできなくなる問題を修正
  - 品質チェックの一括ボタン・チェックボタンが切れる問題、CMS の操作バー、プレゼンモードのスライドを調整

## 0.3.0 — 2026-11-05

- GitHub Pages で公開（https://kazumasaueno.github.io/afro-cms-demo/）。push で自動デプロイ

## 0.4.0 — 2026-11-05

- ページ移動ごとにローディング画面（ロゴ・移動先のページ名・進捗バー、約0.5秒）を表示。画面の読み込みが長引いた場合も同じ画面を出す。動きを減らす設定では短く静的に表示

## 0.4.0 — 2026-11-06

- 画面を立場ごとに 3 つに分けた: 管理者画面（アフロ社内）／ CMS画面（お客様）／ お客様ポータル（お客様）。上部バーの切替で行き来する
- CMS画面: ダッシュボード、公開承認（承認して公開・コメント付きの差し戻し・承認の履歴）を追加。ページ編集は `/cms` から `/cms/pages` へ移動
- お客様ポータル: ホーム、確認・承認（要件定義書・サイトマップ・トップデザイン）、品質確認（お客様側）、レポートを追加
- お客様の画面での操作は「ミナモ珈琲 担当者」の操作として記録するようにした
- 管理者画面のメニューから CMS を外した（管理者画面の「CMSへ」などのリンクは CMS画面を開く）

## 0.5.0 — 2026-11-06

- CMS画面を廃止し、お客様ポータルへ統合した（ページ・お知らせ `/portal/pages`、公開承認 `/portal/publish`）。旧 `/cms` 以下の URL は `/portal/pages` へ転送する
- お客様ポータルのホームに「サイトの更新」（状態ごとのページ数、お知らせを書く・編集する）を追加
- 開発者画面（アフロ制作エンジニア向け、`/dev` 以下）を追加: ダッシュボード、構築タスク、自動チェック（品質チェック A 区分を一括確認）、環境・デプロイ（開発 → 検証 → 本番。本番はトップデザイン承認後のみ）。デプロイ・計測スコア・エラーはシミュレーション／デモデータ
- 以前の保存データはそのまま読み込める（開発者画面のデータが無い場合は初期値で補う）

## 0.5.1 — 2026-11-06

- 旧 CMS画面の URL（`/cms/...`）から移るとき、開くページ・新規作成の指定（`?page=` / `?new=`）も引き継ぐようにした
- タブレット幅（768px・1024px）で全画面の表示崩れが無いことを確認

## 0.6.0 — 2026-11-06

- 開発者画面のデザインを改善（仕様: `docs/design/DEV_AREA_REDESIGN.md`）
  - ダッシュボード: 「次にやること」と「あなたのタスク」を中心に。環境は「最新版／未反映あり」で表示
  - 構築タスク: 状態の選択欄を「次へ進める」ボタンとメニューに。スマホは状態タブで 1 列表示
  - 自動チェック: 初期計測と実行後の差分（例: 71 → 94）を表示。未確認の項目を先に、確認済みは折りたたみ
  - 環境・デプロイ: 次に押すべきボタンだけを強調し、進めないときは理由を表示
  - バージョン・URL・日時を等幅表示に。ボタン色をアプリ共通の青に統一

## 0.6.1 — 2026-11-06

- 開発者画面の「次にやること」が、本番へ公開できる状態と、お客様のデザイン承認待ちも案内するようにした
- 環境カードの版番号を「いま動いている版（最後に成功した版）」に統一（直前のデプロイが失敗していても食い違わない）

## 0.7.0 — 2026-11-06

- 管理者画面のデザインを改善（仕様: `docs/design/ADMIN_AREA_REDESIGN.md`）
  - 読みにくい薄い文字色を濃く、AI 専用の紫を AI 以外で使わないように統一
  - ホーム: 「次の一手」を最上段に、主要ボタンを 1 つに、数値カードを 1 本の帯に
  - プロジェクト詳細: 完了した段階に回答数が出る矛盾を解消。次に必要な作業を唯一の主ボタンに
  - デザイン: 表示中の案をそのまま採用でき、採用ボタンを画面下に固定。採用後の比較表示で採用済みの案を明示
  - サイトマップ: 初期の拡大率を上げて文字を読めるように。スマホではミニマップを隠す
  - 品質チェック: 未完了の項目を概要の直後へ
  - インサイト: 二軸グラフを上下 2 段に分割

## 0.7.1 — 2026-11-06

- MINAMO COFFEE の初期状態を「要件定義の段階（進捗 12%）」にそろえた（要件データは未着手から始まるため、段階表示とボタンの食い違いを解消。AI 要件定義のウィザードから順に体験できる）
  - 以前に開いたブラウザでは古い状態が残るので、画面右上の「↺」でデモを初期化すると反映される
- 要件・サイトマップ・デザインの承認と全ページ構築は、管理者画面で別の案件を選んでいても MINAMO COFFEE（データを持つ案件）の進捗を更新するようにした

## 0.8.0 — 2026-11-06

- 管理者画面・開発者画面・お客様ポータルそれぞれにログイン画面を追加（`/login`・`/dev/login`・`/portal/login`）
  - メールアドレスとパスワード → 二段階認証（6 桁の確認コード）の 2 段階。デモ用アカウント・パスワード・コード（`123456`）を画面に表示し、入力済み
  - デモのため実際の認証は行わない（入力内容は送信せず、ログイン状態だけをこのブラウザに保存）
- 未ログインの画面を開くと、その画面のログインへ移動し、ログイン後に元の画面へ戻る（戻り先は同じ画面のアプリ内のパスだけを受け付ける）
- 上部バーにログアウトを追加（今いる画面だけからログアウト）。画面の切り替えで未ログインの画面を選ぶとログイン画面へ
- 「デモを初期化」してもログイン状態は残る
