# CHANGELOG

## 0.1.0 — 2026-11-05

- 初版。アフロCMS のインタラクティブデモ（主要 9 画面＋設定）
- 実装済み機能・未実装機能は `README.md` を参照

## 0.2.0 — 2026-11-05

- レスポンシブ対応を強化（360〜1440px とスマホ横向き）
  - タッチ環境ではボタン・タブ等の押せる大きさを 44px 以上に、文字は 12px 以上に
  - スマホではダイアログを全画面表示に（ページ作成・画像選択・ページ追加・比較・診断など）
  - 下部タブ・固定バーに内容が隠れないよう余白を調整（iPhone のセーフエリア対応）
  - サイトマップのキャンバスが画面全体を占めてスクロールできなくなる問題を修正
  - 品質チェックの一括ボタン・チェックボタンが切れる問題、CMS の操作バー、プレゼンモードのスライドを調整

## 0.3.0 — 2026-11-05

- GitHub Pages で公開（https://kazumasaueno.github.io/afro-cms-demo/）。push で自動デプロイ

## 0.4.0 — 2026-11-05

- ページ移動ごとにローディング画面（ロゴ・移動先のページ名・進捗バー、約0.5秒）を表示。画面の読み込みが長引いた場合も同じ画面を出す。動きを減らす設定では短く静的に表示

## 0.4.0 — 2026-11-06

- 画面を立場ごとに 3 つに分けた: 管理者画面（アフロ社内）／ CMS画面（お客様）／ お客様ポータル（お客様）。上部バーの切替で行き来する
- CMS画面: ダッシュボード、公開承認（承認して公開・コメント付きの差し戻し・承認の履歴）を追加。ページ編集は `/cms` から `/cms/pages` へ移動
- お客様ポータル: ホーム、確認・承認（要件定義書・サイトマップ・トップデザイン）、品質確認（お客様側）、レポートを追加
- お客様の画面での操作は「ミナモ珈琲 担当者」の操作として記録するようにした
- 管理者画面のメニューから CMS を外した（管理者画面の「CMSへ」などのリンクは CMS画面を開く）

## 0.5.0 — 2026-11-06

- CMS画面を廃止し、お客様ポータルへ統合した（ページ・お知らせ `/portal/pages`、公開承認 `/portal/publish`）。旧 `/cms` 以下の URL は `/portal/pages` へ転送する
- お客様ポータルのホームに「サイトの更新」（状態ごとのページ数、お知らせを書く・編集する）を追加
- 開発者画面（アフロ制作エンジニア向け、`/dev` 以下）を追加: ダッシュボード、構築タスク、自動チェック（品質チェック A 区分を一括確認）、環境・デプロイ（開発 → 検証 → 本番。本番はトップデザイン承認後のみ）。デプロイ・計測スコア・エラーはシミュレーション／デモデータ
- 以前の保存データはそのまま読み込める（開発者画面のデータが無い場合は初期値で補う）

## 0.5.1 — 2026-11-06

- 旧 CMS画面の URL（`/cms/...`）から移るとき、開くページ・新規作成の指定（`?page=` / `?new=`）も引き継ぐようにした
- タブレット幅（768px・1024px）で全画面の表示崩れが無いことを確認
